# EGCO Dashboard — จุดเริ่มต้นสำหรับแก้เว็บไซต์

เว็บหลัก: https://thanachokkusol.github.io/TRIS_AG3/
Repository: https://github.com/thanachokkusol/TRIS_AG3 — branch `main`, Pages เผยแพร่จาก root

## ใช้และส่งงาน
- เปิด `เปิดแดชบอร์ด.cmd` เพื่อดูในเครื่อง หรือเปิดเว็บหลักด้านบน
- เว็บ GPT สองรุ่นเลิกใช้และปิดการเข้าถึงสาธารณะแล้ว เหลือเจ้าของเข้าถึงเพื่อกู้คืนงานเดิม ห้ามนำไปเผยแพร่ซ้ำ
- โหมดทำงานเลือกหน่วยร้อยละ/คะแนนได้ โหมดนำเสนอใช้หน่วยที่เลือก
- งานที่แก้ในเบราว์เซอร์อยู่ใน localStorage ของแต่ละโดเมน ก่อนย้ายงานให้กดสำรองโครงการจากโดเมนเดิม แล้วเปิดไฟล์โครงการบน GitHub ข้อความที่ไม่ได้สำรองจะไม่ย้ายเอง

## แก้ไฟล์ไหน
- `tools/src/workbench.js`: หน้ารายงาน การกรอกข้อมูล tooltip การเลือกเส้น และบทวิเคราะห์
- `tools/src/workbench.css`: สี ฟอนต์ และหน้าตา
- `tools/src/page.html`: โครงหน้า โลโก้ และ metadata สำหรับตัวอย่างลิงก์
- `tools/src/model.js`: สูตรและกติกาการคำนวณ ห้ามเปลี่ยนเพราะปรับหน้าตา
- `tools/src/demo.js`: ข้อมูลจำลองแยกจากข้อมูลจริง
- `tools/project_source.json`: นิยามแบบสอบถามและตำแหน่งเซลล์ต้นทาง
- `tools/build_local.py`: อ่าน Excel v8 แบบ read-only แล้วฝังข้อมูลและ source เป็น HTML เดียว
- `index.html`: ผลลัพธ์สำหรับ GitHub และเปิดในเครื่อง ห้ามแก้ไฟล์นี้อย่างเดียวแล้วปล่อยให้ source ไม่ตรงกัน
- `dist/index.html`: สำเนาสำหรับตรวจในเครื่อง สร้างจาก build เดียวกัน
- `.gitignore`: กัน tools, JSON, ZIP และไฟล์ภายในไม่ให้ส่งขึ้น repository

## วิธีแก้และอัปเดต
1. ตรวจ `git status` และ `git fetch origin main` ก่อนเริ่ม เปรียบเทียบกับเว็บจริง ห้ามใช้ชื่อเวอร์ชันเป็นหลักฐานว่าล่าสุด
2. แก้ source เดิมใน `tools/src` ตรวจ syntax ด้วย `node --check tools/src/workbench.js`
3. รัน `python tools/build_local.py` จากโฟลเดอร์นี้ (ต้องมี openpyxl) ถ้าแก้คะแนนใน Excel ต้องคำนวณและบันทึก Excel ให้เสร็จก่อน
4. เปิดตรวจ `index.html` หรือใช้ `python -m http.server 8770 --bind 127.0.0.1` จากโฟลเดอร์นี้ ตรวจคณะ 5 คณะ บุคคล 15 คน ทั้งร้อยละและคะแนน มือถือ tooltip และการซ่อน/แสดงชุดกราฟ
5. ตรวจ diff: `tools/src/model.js` และ Excel ต้องไม่เปลี่ยนเมื่อแก้หน้าตา จากนั้นส่ง `index.html`, favicon สองไฟล์ และคู่มือนี้ขึ้น branch main ของ repository เดิมเท่านั้น ใช้ git push เมื่อมีสิทธิ์ หรือ Upload files บน GitHub
6. รอ Actions `pages build and deployment` สำเร็จ แล้วเปิดเว็บจริงตรวจซ้ำ ห้ามส่ง tools, Excel, Word, JSON หรือ `.openai` ขึ้นเว็บ
7. GitHub และโฟลเดอร์นี้เป็นชุดหลักเพียงชุดเดียว ไม่สร้าง Site GPT เพิ่ม ไม่ย้อนกลับใช้ชุดเก่า

## สูตรและคำที่ต้องคงไว้
- ต้นทาง `../01_Data/DB_EGCO_v8.xlsx` คะแนนดิบ 1–4 ช่องว่าง/N/A ไม่ใช่ศูนย์
- ค่าเริ่มต้น: เฉลี่ยทุกข้อหลักเท่ากัน ข้อย่อย (1), (2) รวมเป็นข้อหลัก 1.6 ก่อน ร้อยละ = คะแนน / 4 × 100
- ยังคงตัวเลือกวิธีเฉลี่ยและสูตรร้อยละในโครงการ ไม่เขียนทับคำตอบเมื่อเปลี่ยนหน่วย
- คะแนน 4 ตำแหน่ง ร้อยละ 2 ตำแหน่ง คำนวณก่อนปัดเศษ ช่องว่าง = ตนเอง − ไขว้ ค่า + สีเขียว ค่า − สีแดง
- ชุดรายบุคคล: ผลการประเมินตนเอง / ผลการประเมินแบบไขว้ / ผลการประเมินรายบุคคลเฉลี่ย / ผลการประเมินแบบไขว้เฉลี่ย
- รายคณะ: ผลการประเมินรายคณะเพียงชุดเดียว ใช้ชื่อด้านเต็มตามรายงาน แสดงค่าข้างจุด ไม่แสดงเส้นค่าเฉลี่ยทั้งกราฟคณะรวมและกราฟรายด้าน
- กราฟเรดาร์และแท่งใช้คำอธิบายแบบปุ่ม กดแล้วขีดฆ่าและซ่อนชุดนั้น ชื่อชุดยังคงอยู่เสมอ ไม่มี checkbox ค่าเฉลี่ย
- แท่งมีเส้นประค่าเฉลี่ยและ tooltip ใช้ค่าชุดเดียวกับเรดาร์
- ไม่แสดงรายชื่อผู้ประเมินไขว้ที่ประเมินกรรมการแต่ละท่าน
- บทวิเคราะห์ใต้กราฟใช้หัวข้อ ข้อสังเกต/ข้อเสนอแนะ และข้อความว่าง ยังไม่มีบทวิเคราะห์
- ความเห็นแสดงชื่อผู้เขียน แล้วบรรทัดถัดไปเป็น ประเด็นการพัฒนาที่สนใจ: … สำหรับตนเอง/คณะ หรือ ประเด็นการพัฒนาต่อท่านอื่นในการประเมินไขว้: … สำหรับความเห็นที่ผู้นั้นเขียนในแบบไขว้ ไม่แจกความเห็นระดับแบบไปเป็นความเห็นต่อผู้ถูกประเมิน

## การกู้คืนและขอบเขต
- `../.workingspaceG/percent_view/legacy_sites_before_git_only.zip` เก็บชุด 05_Site เดิม รวมคู่มือและประวัติ Site ก่อนยุบ
- ห้ามแก้ `.workingspaceC` หรือ `.workingspaceClaude`
- งานนี้ไม่แก้ Excel, แม่แบบ Word, ตัวสร้าง Word หรือผลรายงาน
- ไม่มี API/CDN/ฐานข้อมูล บทวิเคราะห์ใน localStorage ไม่เขียนกลับ Excel หรือ GitHub โดยอัตโนมัติ

การเลือกผู้รับรายงานใช้คลิกแถวบนกราฟภาพรวม ไม่มี dropdown หรือรายละเอียดทุกคณะ คณะ BOD อยู่แถวแรก ตามด้วยคณะอื่นเรียงคะแนน พร้อมรหัสและชื่อเต็ม ปุ่มคำอธิบายกราฟภาพรวมซ่อนแท่ง/ขีดอ้างอิงแยกกันโดย tooltip ยังคงครบทุกชุด

รายบุคคลมีแถวค่าเฉลี่ยสังเคราะห์เป็นแถวแรกและค่าเริ่มต้น (รวม 16 แถว แต่บุคคลจริงยัง 15 คน) คำนวณค่าเฉลี่ยจากค่าของบุคคลที่มีข้อมูลแต่ละข้อ/ด้าน ให้แต่ละคนมีน้ำหนักเท่ากัน ไม่เพิ่มบุคคลหรือคำตอบในข้อมูลดิบ ข้อสังเกต/ข้อเสนอแนะอยู่ท้ายตารางทั้งสองหน้า ปุ่มด้านและภาพรวมเลื่อนไปยังตารางด้านนั้นหรือกราฟภาพรวม
แก้เฉพาะหน้าตาใช้ `python tools/build_local.py --html-only` เพื่อใช้ข้อมูลที่ตรวจแล้วโดยไม่ต้องเปิด Excel ใหม่
